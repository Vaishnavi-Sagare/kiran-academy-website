# Kiran Academy Website Clone

A responsive HTML/CSS/JavaScript educational project inspired by the structure and UX patterns of The Kiran Academy website.

## Files
- index.html
- style.css
- script.js

## Run locally
Open `index.html` in VS Code and use the Live Server extension, or double-click the file.

## GitHub
```bash
git init
git add .
git commit -m "Initial website"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```

## Netlify
Connect the GitHub repository to Netlify and deploy the `main` branch. After that:
1. Edit files in VS Code.
2. `git add .`
3. `git commit -m "Update website"`
4. `git push`
5. Netlify automatically deploys the new commit.

The demo form is frontend-only; connect it to a backend/form service if you want to receive submissions.
